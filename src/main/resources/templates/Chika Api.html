HTTP API Reference

Sign In

POST   http://chika-server.herokuapp.com/auth/signin

• Example request:

POST http://chika-server.herokuapp.com/auth/signin

Body:

{
 "usernameOrEmail": "chika123",
 "password": "123456"
}

• Example response:

{
 "tokenType: "Bearer",
 "accessToken": "eyJhbGciOiJIUzI1NiIsIn.eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZ0IjoxNTE2MjM5MDIyfQ.SflKxwRJSMeKKF2QT4Qssw5c"
}

Sign Up

POST   http://chika-server.herokuapp.com/auth/signup

• Example request:

POST http://chika-server.herokuapp.com/auth/signup

Body:

{
 "name": "Chika Smarthome",
 "username": "chika123",
 "email": "chika@gmail.com",
 "password": "123456"
}

• Example response:

{
 "success: true,
 "message": "Register successfully"
}
