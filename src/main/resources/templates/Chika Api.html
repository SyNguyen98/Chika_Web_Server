Chika API

Authentication
POST /auth/signin POST /auth/signup
User
GET /user GET /user/{username} PUT /user PUT /user/{username}/role PUT /user PUT /user/email/{email} PUT /user/{username}
Switch
GET /switch GET /switch/{switch-id} POST /switch/num_of_device/{num-of-device} PUT /switch/name PUT /switch/user DELETE /switch/{switch-id}
Module IR
GET /module_ir GET /module_ir/{module-id} POST /module_ir PUT /module_ir/name PUT /module_ir/user DELETE /module_ir/{module-id}
Room
GET /room POST /room PUT /room DELETE /room/{room-id}
Device
GET /device/room/{room-id} GET /device/switch/{switch-id} GET /device/{device-id} POST /device/switch/{switch-id} PUT /device/info PUT /device/state POST /device/{device-id} GET /device/{device-id}/history DELETE /device/{device-id}/history
Sensor
GET /sensor/room/{roomId} GET /sensor/{sensor-id} POST /sensor PUT /sensor DELETE /sensor/{sensor-id}
Remote IR
GET /remote_ir/room/{room-id} POST /remote_ir/num_of_button/{number-of-button} PUT /remote_ir DELETE /remote_ir/{remote-id}
IR Value
GET /ir/remote/{remote-id} PUT /ir
Image
GET /image/{image-id} POST /image
Audio
GET /audio/{audio-id} POST /audio

Sign In

POST http://chika-server.herokuapp.com/auth/signin

Example request:

POST http://chika-server.herokuapp.com/auth/signin

Body: {"usernameOrEmail": "chika123",
"password": "123456"}

Example response:

{"tokenType: "Bearer", "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkpvaG4gRG9lIiwiaWF0IjoxNTE2MjM5MDIyfQ.SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c"}

Sign Up

POST http://chika-server.herokuapp.com/auth/signup

Example request:

POST http://chika-server.herokuapp.com/auth/signup

Body: {"name": "Chika Smarthome",
"username": "chika123", "email": "chika@gmail.com", "password": "123456"}

Example response:

{"success: true, "message": "Register successfully"}

Get all users (admin only)

GET http://chika-server.herokuapp.com/user/all

Example request:

GET http://chika-server.herokuapp.com/user/all

Header: "Authorization": "Bearer {token}"

Example response:

[{"name": "Chika Smarthome", "username": "chika123", "email": "chika@gmail.com", "createAt": "20:00 27/09/2019", "role": "ROLE_ADMIN"}, {"name": "Chika User", "username": "user123", "email": "user@gmail.com", "createAt": "06:00 28/09/2019", "role": "ROLE_HOME_MASTER"}

Update user's information

PUT http://chika-server.herokuapp.com/user

Example request:

PUT http://chika-server.herokuapp.com/user

Header: "Authorization": "Bearer {token}"

Body: {"name": "chika456",
"email": "chika456@gmail.com"}

Example response:

{"name": "Chika Smarthome", "username": "chika456", "email": "chika456@gmail.com", "createAt": "20:00 27/09/2019", "role": "ROLE_ADMIN"}

Update user from ROLE_HOME_USER to ROLE_HOME_MASTER

PUT http://chika-server.herokuapp.com/user/{username}/role

Example request:

PUT http://chika-server.herokuapp.com/user/chika123/role

Header: "Authorization": "Bearer {token}"

Example response:

{"name": "Chika Smarthome", "username": "chika123", "email": "chika@gmail.com", "createAt": "20:00 27/09/2019", "role": "ROLE_HOME_MASTER"}

PUT http://chika-server.herokuapp.com/user/password

Header: "Authorization": "Bearer {token}"

Send mail to reset password

PUT http://chika-server.herokuapp.com/user/email/{email}

Example request:

PUT http://chika-server.herokuapp.com/user/email/chika123@gmail.com

Header: "Authorization": "Bearer {token}"

Example response:

{"success": true, "message": "Email has sent"}

Delete user by username

DELETE http://chika-server.herokuapp.com/user/{username}

Example request:

DELETE http://chika-server.herokuapp.com/user/chika123

Header: "Authorization": "Bearer {token}"

Example response:

{"success": true, "message": "User has been deleted"}
